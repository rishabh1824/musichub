# 🎵 MusicHub – Full-Stack Music Streaming Platform

MusicHub is a **full-stack web-based music streaming platform** that enables users to browse, search, and play music with personalized recommendations.  
The project focuses on **secure authentication**, **data-driven insights**, and **AI-powered recommendations**.

---

## 💻 GitHub Repository
🔗 https://github.com/rishabh1824/musichub

---

## 🚀 Key Features

- 🔐 **Secure User Authentication**
  - User registration and login system
  - MD5-hashed password storage
  - Secure password recovery via email using **PHPMailer**

- 🔎 **Music Search & Streaming**
  - Real-time song search
  - Dynamic MP3 playback
  - Interactive UI for seamless browsing

- 📊 **User Analytics & Insights**
  - Tracks listening history
  - Displays most-played songs
  - Session duration and recent activity monitoring

- 🤖 **AI-Based Music Recommendations**
  - Personalized recommendations using **collaborative filtering**
  - Built with **Python, Pandas, and Scikit-learn**
  - Recommendations based on user listening behavior

- 📱 **Responsive UI**
  - Optimized for desktop and mobile devices
  - Clean and intuitive user interface
